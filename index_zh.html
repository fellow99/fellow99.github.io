Pi Desktop

Pi Agent 运行环境的 Electron 外壳——上游 Pi 与 Pi Web 100% 原样，零上游改动。Next.js 服务跑在应用主进程内，因此你现有的 ~/.pi 会话、凭据与扩展都能直接沿用。 覆盖 Windows、macOS 与 Linux，并提供基于 Electron 与进程内 Node 运行时的两个鸿蒙版别。

Node Bridge

把真正的 Node.js 运行时嵌进 Android 或鸿蒙应用自身的进程——不是 WebView、云函数或子进程。 JNI/NAPI 引导层以 dlopen 加载 libnode.so 并调用 node::Start，通过双向 JSON 在 JavaScript 与 Kotlin / ArkTS 之间通信。 共四个包：每个平台各一个桥接库与引擎运行时，发布于 Maven Central 与 ohpm （Node v24.2，arm64-v8a）。

  • Node.js
  • Android
  • HarmonyOS
  • JNI/NAPI
